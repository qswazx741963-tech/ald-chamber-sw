# 安全狀態

## 一、什麼時候進安全狀態

| 觸發 | 誰偵測 | 範圍 |
| --- | --- | --- |
| IPC 心跳逾時（預設 1 s）或網路斷線 | 主控板 | 全機 |
| 背板 SYNC 逾時（預設 1 s） | 各執行板 | 該板 |
| SAFE 線被拉低（任何一塊板、EMO） | 硬體 + 各板 | 全機 |
| IPC 下 ENTER_SAFE | 主控板 | 全機 |
| 開機 | 各板 | 開機一律在安全狀態，等 RESET_ALARM |

解除：IPC 連線正常 + SAFE 線正常 + EMO 正常 + IPC 下 RESET_ALARM。

## 二、ALD 的安全狀態「不是全部關掉」

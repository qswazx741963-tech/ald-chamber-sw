# 背板規格（草案）

背板 6 槽（3U Eurocard、DIN 41612 Type C 96 pin），槽 0 = 主控板、槽 1~5 = 執行板；純被動板，沒有 IC。2026-11-24 定案。

## 一、背板訊號

| 訊號 | 說明 |
| --- | --- |
| 24V_LOGIC / 24V_IO / GND | 兩路 24 V 分開：24V_LOGIC 給 MCU、通訊，EMO 也不切；24V_IO 給電磁閥、繼電器線圈，經安全繼電器，**只有 EMO 切**。每槽 24V_IO 以 3 A 設計。各板自己降壓到 5 V / 3.3 V |
| CAN FD H / L | 5 Mbps 資料段、1 Mbps 仲裁段；背板兩端 120 Ω 終端 |
| SAFE | 開汲極，背板 4.7 kΩ 上拉到 24V_LOGIC。任何一塊板拉低 = 全機進安全狀態（關前驅物、**維持 N2 purge**、加熱保溫）。**不切整條 24V_IO**：N2 purge 閥是常閉（NC），切 24V_IO 會把 purge 一起關掉。但危險輸出仍有**硬體切斷**、不靠韌體：各執行板用 SAFE_N（經施密特）直接拉低危險輸出驅動器的致能腳（前驅物 ALD 閥、RF enable、加熱 SSR 驅動），N2 purge 閥的驅動器不接這個閘控、維持原狀態。主控板外部看門狗 TPS3430 的 WDO 也接在這條線，並同時放開 SV / TGV / TRANSFER PERMIT 繼電器 |
| SYNC | 主控板送出 1 kHz 方波（TODO），讓各板計時對齊 |
| SLOT_ID[3:0] | 每槽在背板上固定接地 / 懸空，板子讀到就知道自己是幾號槽（0 = 主控板，1~5 = 執行板，共 6 槽）。0~5 只要 3 bit，SLOT_ID3 在背板固定接地；保留 4 bit 是為了日後擴充槽數不用改板卡 |
| PRESENT_N1~5 | 插板檢知：板卡把自己的 PRESENT_N 接地，只有槽 0（主控板）讀，用來區分「沒插」跟「當機」 |

## 二、CAN FD 訊框

11-bit ID = `[10:8] 類型 | [7:4] 槽號 | [3:0] 分段號`，數字越小越優先。

| 類型 | 值 | 方向 | 週期 | 內容 |
| --- | --- | --- | --- | --- |
| SAFE | 0 | 任一 → 全部 | 事件 | 進安全狀態（SAFE 線的軟體備援） |
| SYNC | 1 | 主控 → 全部 | 10 ms | 心跳、時間、旗標（SAFE_REQ / RUN_OK） |
| HR | 2 | 主控 → 槽 n | 10 ms | 該槽 HR 表（**經過互鎖過濾後**），每段最多 30 個暫存器 |
| IR | 3 | 槽 n → 主控 | 10 ms | 該槽 IR 表 |
| EVENT | 4 | 槽 n → 主控 | 事件 | 警報（TODO） |
| WAVE | 5 | 槽 n → 主控 | 每 cycle | 壓力波形區塊（TODO） |
| HELLO | 6 | 槽 n → 主控 | 1 s | 板型、韌體版本、map_version |

資料段格式：`起始位址(2) + 個數(1) + 保留(1) + 資料(2×n)`，補到 CAN FD 合法長度。程式：`firmware/common/bp_proto.c`。

**為什麼週期整份傳、不只傳變化**：掉一包不需要重送機制，下一輪自動補回，狀態永遠收斂。

頻寬估算：5 槽 × (IR 約 60 + HR 約 150) 個暫存器 × 2 byte × 100 次/秒 ≈ 210 kB/s，5 Mbps CAN FD 約可跑 400 kB/s 有效資料，**約 50% 負載**。
槽數增加時，HR 改成「變化才送 + 每 100 ms 整份補一次」即可。

## 三、一次性命令

HR `COMMAND`（START / STOP / RESET_ALARM）由主控板轉送 3 輪後自動清回 NONE，執行板只在「值改變」時執行一次。
